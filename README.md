
## Overview
My App is a modern web application built with **Next.js** that provides a secure learning platform with authentication, course management, and exam functionality.

## Features

### 🔐 Authentication
- Secure user login with username/PIN verification
- NextAuth.js integration for credential-based authentication
- Password fetching with admin verification

### 📚 Courses
- Dynamic course management by type
- Organized course structure with nested routing
- Type-based course categorization

### 📝 Exams
- Interactive exam functionality for each course type
- Integrated exam system under course routes

### 🎨 UI/UX
- Responsive design with Tailwind CSS
- Smooth animations and transitions
- Dark/Light mode support
- Custom button and input components
- Modern gradient effects

## Tech Stack

- **Framework:** Next.js 13+ (App Router)
- **Styling:** Tailwind CSS
- **Authentication:** NextAuth.js
- **HTTP Client:** Axios
- **Database:** MongoDb
- **Language:** JavaScript/React
